# 서버 부하 확인

## 테스트 환경
같은 codespaces에서 nginx와 ab 실행

## 실행 명령어
ab -n 10000 -c 20 http://localhost:8080/
ab -n 10000 -c 100 http://localhost:8080/

## 결과 비교
동시 요청 수를 5배로 늘렸지만 처리량은 2,943에서 3,177로 큰 차이가 없었고, 평균 요청 시간은 6.796에서 31.474로 길어졌다.

## 동시 요청 100의 일부 요청 확인
평균은 약 31ms 였지만 p95, p99는 51ms, 69ms로 그보다 오래 걸렸다

## 결론
처리량은 조금 증가했고, 요청시간은 늘었으며, 실패는 없었다. 같은 Codespaces에서 부하 도구와 서버가 자원을 공유하므로, 이 결과만으로 nginx의 최대 처리량을 판단할 수는 없다.
